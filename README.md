# 目标跟踪助手

一个面向 AstrBot 的个人目标插件：通过自然语言创建目标，按每日次数打卡或累计计时，并支持图片识别与可选每日提醒。

## 功能

- 次数打卡：每个目标可设置每天 `N` 次，支持一次补记多次。
- 每日计时：可直接补记分钟，也可用“开始/结束”自动计时。
- 自然语言：新增、修改、记录、查询、提醒和归档均可由当前 Agent 通过 LLM 工具执行。
- 图片识别：图片与单个次数目标高置信匹配时自动打卡；计时目标会先询问是否记录及时长。
- 每日提醒：管理员总开关默认关闭；开启后，每位用户可为每个目标单独设置提醒时间。
- 统计：查看今日进度、达标状态与最近 1～90 天的完成情况。

## 使用要求

- AstrBot 4.9.2 或更高版本。
- 图片匹配需当前会话的聊天模型支持图片输入。

## 自然语言示例

- “帮我创建一个每天背单词 3 次的打卡目标。”
- “新增每天阅读 30 分钟。”
- “今天已经背了两轮单词。”
- “开始阅读计时。” / “结束阅读计时。”
- “昨天跑步了 45 分钟，帮我补一下。”
- “每天晚上九点提醒我阅读。”
- “这周目标完成得怎么样？”

## 明确指令

- `/目标 帮助`：显示帮助。
- `/目标 新增 <名称> <打卡|计时> <每日次数|分钟>`：创建目标。
- `/目标 列表` 或 `/目标 今日`：查看今日进度。
- `/目标 打卡 <名称> [次数]`：记录一次或多次打卡。
- `/目标 计时 <名称> <分钟>`：直接补记时长。
- `/目标 开始 <名称>` / `/目标 结束 <名称>`：开始或结束实时计时。
- `/目标 统计 [天数]`：查看最近的达标统计。
- `/目标 提醒 <名称> <开启|关闭|状态> [HH:MM]`：设置目标提醒。
- `/目标 归档 <名称>` / `/目标 恢复 <名称>`：归档或恢复目标；归档会关闭该目标的提醒。
- `/目标 删除 <名称>`：永久删除目标及其记录。
